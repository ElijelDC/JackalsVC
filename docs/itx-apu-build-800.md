# €800 Lian Li Mini-ITX Build — Amazon.de vs .ie vs .it (Ireland)

Checked **28 Jul 2026**. Goal: cheapest *good* parts that ship to Ireland. Case stays off Amazon (Black A4-H2O).

## Verdict: where to shop

| Store | Verdict for Ireland |
| --- | --- |
| **Amazon.ie** | Best default — free IE delivery, no customs. Use for CPU, PSU, SSD. |
| **QuietPC.ie** | Best for **Gigabyte B650I AX** board (Irish stock, ~€139). |
| **Amazon.de** | Sometimes cheaper B650I AX, but check “Lieferung nach Irland”. DDR5 currently gouged here too. |
| **Amazon.it** | Skip for this build — CPU listings were ~€400+; not competitive. |
| **Amazon.co.uk** | Worth checking for PSU/RAM; ships to IE. SF750 was ~£115 (~€135) earlier — often beats .ie. |
| **OcUK / Scan** | Use for **case**. **RAM on OcUK is not cheap anymore** (~£360–430 for 32GB EXPO). |

**DDR5 reality (Jul 2026 shortage):** A 32GB DDR5-6000 kit is **~€250–€620** depending on stock luck — not the old €90–120. OcUK’s Kingston FURY Beast EXPO is **£359–£429** (~€420–500). If you found a real **~€250** EXPO kit that ships to IE, that’s a strong buy — take it. Skip ghost Amazon listings that still show ~€100 (often marketplace bait / OOS).

## Checkout checklist (Ireland)

1. On every Amazon page: destination **Ireland** / “Deliver to Ireland”.  
2. Prefer **Amazon** or **Fulfilled by Amazon** sellers.  
3. For Amazon.de: confirm IE delivery before pay.  
4. **RAM:** buy a real in-stock kit around **€250** if you found one; skip €400–580 gouge and skip fake ~€100 listings.  
5. After build: enable **EXPO** in BIOS; update BIOS if needed for 8000G (Q-Flash / Flashback).

- SFX / SFX-L PSU only
