## Assumptions locked in

### Teams & roster
- **3 National League teams:** Division 2 Men, Division 3 Women, Division 3 Men
- **14 members per team** → **42 members** for budgeting
- **Training nights:** D3 Men Monday · D2 Men Wednesday · D3 Women Friday (Meakstown)
- **Home matches:** 7 + 7 + 7 = **21** home games (Luttrellstown, Sundays)

### Venues & booking rules
- **Training:** Meakstown · Mon / Wed / Fri · **81 sessions** (1 Oct – 30 Apr, excl. Christmas + bank holidays)
- **Home matchdays:** Luttrellstown · **0.5h setup once per home Sunday** + **2.5h per match**
- Home-day mix from **25/26 schedule** (9 single / 4 double / 0 triple on 17 homes → 13 Sundays) **plus ≥1 guaranteed triple week** for 21 homes → **14.76 setup Sundays** (planning estimate)

### Rates used
| Item | Rate |
|------|------|
| Meakstown | €40 / hour |
| Luttrellstown | **€48.50 / hour** |
| Coach (training only) | €25 / session |
| Referees (worst case) | €45 / home match (€25 + €20, hired every home) |
| Kit (player pays) | €45 / player — collected **before** membership |
| Kit subsidy (from membership) | €5 / member × 42 = **€210** — club-side only, not buffer |
| Canva | **€12 / month** × 7 months (Oct–Apr) |
| Google Drive | **€2 / month** × 7 months |
| Website (upkeep) | **€7 / month** × 7 months |

### Excluded from membership pool
- **Player kit payments** (€45 each — separate collection) · VI affiliation · cups/playoffs · fun sessions · away travel · equipment

> The **€5 kit subsidy per member** comes **from** membership revenue (+€5 on each published fee) and is earmarked for kit — it does not count as operating buffer.
